# 🤖 System Bot | بوت السيستم المتكامل

**System Bot** هو بوت ديسكورد متطور ومتعدد الاستخدامات، تم بناؤه وتطويره باستخدام مكتبة `Discord.js` وبيئة تشغيل `Node.js`. صُمم هذا البوت ليجمع كل ما يحتاجه سيرفرك في مكان واحد، بدءاً من أدوات الإدارة الصارمة وحماية السيرفر، وصولاً إلى الألعاب وأنظمة التفاعل الترفيهية.

---

## 🌟 المميزات الرئيسية (Features)

* **الأوامر الإدارية (Admin Commands):** أدوات احترافية للمشرفين تشمل الطرد، الحظر، كتم الصوت، وتطهير الشات لإدارة السيرفر بكل سهولة.
* **النظام الترفيهي والألعاب (Fun & Games):** مجموعة واسعة من الألعاب والأوامر الترفيهية لزيادة تفاعل الأعضاء داخل السيرفر.
* **نظام الترحيب والمغادرة:** تخصيص رسائل ترحيبية مميزة للأعضاء الجدد عند انضمامهم.
* **الأوامر العامة (General Commands):** توفير معلومات مفصلة عن السيرفر، الأعضاء، البوت، وزمن الاستجابة.

---

## 🛠️ المتطلبات الأساسية (Prerequisites)

قبل البدء في تشغيل البوت، تأكد من تثبيت البرامج التالية على جهازك أو السيرفر الخاص بك:
* **Node.js** (الإصدار 16.x أو أحدث)
* **npm** (مدير حزم Node)

---

## 🚀 طريقة التثبيت والتشغيل (Installation & Setup)

اتبع الخطوات البسيطة التالية لتشغيل البوت محلياً أو على سحابة استضافة:

### 1. تحميل المستودع (Clone)
قم بنسخ المستودع إلى جهازك عن طريق تشغيل الأمر التالي في أمر الـ Terminal:
```bash
git clone https://github.com
cd System-Bot
```

### 2. تثبيت الحزم البرمجية (Dependencies)
قم بتثبيت كافة المكتبات والحزم اللازمة للمشروع:
```bash
npm install
```

### 3. إعداد ملف التكوين (Configuration)
* ابحث عن ملف الإعدادات (مثل `config.json` أو ملفات قواعد البيانات المرفقة لديك).
* قم بإضافة **توكن البوت (Bot Token)** والبادئة الخاصة بالأوامر (Prefix).
*(تأكد من تفعيل خيارات الـ **Intents** الثلاثة من صفحة المطورين في ديسكورد لضمان عمل البوت بشكل صحيح)*.

### 4. تشغيل البوت (Run)
ابدأ تشغيل البوت مباشرة باستخدام الأمر التالي:
```bash
node index.js
```
